# Tomba Wiki Bot

Bot that posts recent edits on the [Tomba Club Wiki](https://tomba.club/wiki/) to the [Discord server](https://discord.gg/tCtWkYjxZh).

Uses [CronBot](https://github.com/msikma/cronbot).
